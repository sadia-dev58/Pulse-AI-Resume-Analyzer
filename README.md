# PulseAI – Smart Resume Analyzer 🚀

PulseAI is an AI-powered Resume Analyzer that helps job seekers evaluate and optimize their resumes according to specific job descriptions. Powered by Google Gemini 1.5 Flash, it provides intelligent feedback, resume scoring, and actionable suggestions to improve ATS compatibility.

## ✨ Features

- **AI-Powered Resume Analysis:** Analyze resumes using Google Gemini AI.
- **Job Description Matching:** Compare resumes against target job descriptions.
- **Resume Scoring:** Get an overall resume evaluation.
- **ATS Compatibility:** Identify areas that can improve ATS performance.
- **Smart Suggestions:** Receive actionable recommendations for improvement.
- **Resume Upload:** Upload resumes in `.txt` format.
- **Interactive UI:** Modern interface with responsive visual elements.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Gemini 1.5 Flash API
- Font Awesome

## ⚙️ How to Use

1. Open the PulseAI application.
2. Enter your login credentials.
3. Navigate to the Resume Analyzer section.
4. Upload your resume in `.txt` format.
5. Paste the target Job Description.
6. Click **Analyze Resume**.
7. Review your AI-generated feedback and suggestions.

## 🔐 API Configuration

Configure your Google Gemini API key securely.
